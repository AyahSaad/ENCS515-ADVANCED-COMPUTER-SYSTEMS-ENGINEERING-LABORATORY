# 🎮 Android Number Guessing Game App
A simple Android game where the user tries to guess a randomly generated number between 1 and 100 within a limited number of attempts. The app gives feedback on each guess, resets after win/loss, and tracks remaining attempts.

# 🧠 Game Rules
You have 7 attempts to guess a randomly generated number between 1 and 100.

After each guess:

If correct → 🎉 you win and the game resets.

If wrong → you'll be told whether your guess is too high or too low.

If attempts run out → you lose, the correct number is shown, and a new number is generated.

A Reset button allows you to start the game manually anytime.

# 🔧 Features
Random number generation between 1–100.

Tracks remaining attempts.

Feedback on each guess.

Input validation for numbers outside the allowed range.

UI interaction with buttons and text fields.

Preserves last generated number when showing loss result.

# 🧪 How to Run the App
Open the project in Android Studio.

Connect an emulator or physical device.

Click Run ▶️ to build and launch the app.
